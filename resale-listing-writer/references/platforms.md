# Platform notes

Platforms change their forms from time to time. If the user says a field or category looks different in their app, follow what they see.

## Vinted

- **Audience:** very large in France and across Europe; buyers search by brand + piece name.
- **Language:** French for vinted.fr; match the local site otherwise.
- **Title:** short and keyword-led: `Sézane <piece name> <category> <colour> <size>`.
- **Condition categories** (FR / EN):
  - Neuf avec étiquette / New with tags
  - Neuf sans étiquette / New without tags
  - Très bon état / Very good
  - Bon état / Good
  - Satisfaisant / Satisfactory
- **Structured fields** (brand, size, colour, material) are filled separately in the app; still repeat size and colour in the description, because buyers read it.
- **Conventions:** buyers expect to make offers and to bundle ("lot"). A short line like "Remise possible sur les lots" helps. No hashtags needed.

## Vestiaire Collective

- **Audience:** buyers who expect premium presentation and are attentive to condition.
- **Language:** English or French depending on the site the user lists on.
- **Title:** usually generated from the brand, category and colour fields; focus on the description.
- **Condition categories:**
  - Never worn, with tag
  - Never worn
  - Very good condition
  - Good condition
  - Fair condition
- **Conventions:** a more polished, factual tone. Include the composition and precise measurements. Mention proof of purchase if the user has it. Vestiaire may check items, so the condition must be accurate.

## Depop

- **Audience:** younger, international, style-driven.
- **Language:** English.
- **Description:** the first line acts as the title, so start with `Sézane <piece name> <category>`.
- **Condition categories:**
  - Brand new
  - Like new
  - Used – Excellent
  - Used – Good
  - Used – Fair
- **Conventions:** a slightly more casual tone is fine. Finish with up to 5 relevant hashtags, e.g. `#sezane #parisianstyle #frenchgirl #cardigan #knitwear`. Only use tags that describe the item.

## eBay

- **Audience:** international, search-driven.
- **Language:** the site's language (usually English).
- **Title:** up to 80 characters. Pack it with true keywords: `Sézane Gaspard Cardigan Ecru Alpaca Wool Size S Women's Knit`.
- **Condition:** New with tags, New without tags, New with defects, Pre-owned. Describe Pre-owned wear in the condition description field.
- **Item specifics:** brand, size, size type, colour, material, style, department. Fill in as many as the user knows, because they feed eBay search filters.
- **Conventions:** give measurements in inches as well as cm. Add a plain line on returns/shipping only if the user tells you their policy.

## Leboncoin

- **Audience:** France, general marketplace.
- **Language:** French.
- **Title:** `Cardigan Sézane Gaspard écru taille S`. Put the category word first; it matches how people browse there.
- **Condition:** État neuf, Très bon état, Bon état, État satisfaisant.
- **Conventions:** say whether the item can be handed over in person ("remise en main propre") or shipped, if the user says so.

## Instagram / Sézane community groups

- **Format:** a caption with the key facts in a short list, then price and how to contact or reserve.
- **Conventions:** some groups have their own rules (price format, proof of purchase, no external links). Remind the user to check the group rules.
